#### 慢查询以及简单优化

#### 如何找到慢查询？

##### 	开启慢查询日志

```
SHOW VARIABLES LIKE 'slow_query_log';
```

如果结果是 `OFF`，就需要把它打开。

​	开启方式有两种：

​		1、动态开启 (无需重启)

```
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 0.5; -- 记录执行超过0.5秒的查询
SET GLOBAL slow_query_log_file = '/var/log/mysql/slow-query.log';
```

`long_query_time` 的单位是秒，可以设置为小数，比如0.5秒。默认值是10秒。

​		2、永久生效 (修改配置文件)

1. 找到MySQL的配置文件 `my.cnf`（在Linux系统中通常是 `/etc/mysql/my.cnf` 或 、`/etc/my.cnf`）。
2. 在 `[mysqld]` 部分下添加或修改以下参数：

```sql
[mysqld]
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow-query.log
long_query_time = 0.5
```

1. 重启MySQL服务让配置生效：

```sql
	sudo systemctl restart mysql
```

​	查看具体哪些慢的sql

#### `mysqldumpslow` (官方自带)

这是一个非常实用的轻量级工具，尤其适合快速统计。

```
# 取出查询时间最长的10条SQL
mysqldumpslow -s t -t 10 /var/log/mysql/slow-query.log

# 取出平均查询时间最长的10条SQL
mysqldumpslow -s at -t 10 /var/log/mysql/slow-query.log

# 取出锁定时间最长的5条SQL
mysqldumpslow -s l -t 5 /var/log/mysql/slow-query.log
```

第三步找到了可疑的SQL，就可以使用EXPLAIN来对SQL进行具体的分析了。
